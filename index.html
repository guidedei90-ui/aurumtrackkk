Conecte quantas fontes quiser. Cada uma alimenta o painel com gasto, cliques e impressões; a receita real de cada venda vem sempre do webhook de pagamento, casada pela campanha.

Meta Ads (Facebook)

Não conectado

Business Manager → Configurações do negócio → Usuários do sistema → gerar token com permissão ads_read. O ID da conta fica em Configurações do negócio → Contas de anúncios.

Google Ads

Não conectado

Precisa de um Developer Token aprovado no Google Ads API Center, e um Client ID/Secret + Refresh Token gerados via OAuth2 (Google Cloud Console → credenciais). Por enquanto o Google Ads entra só no nível de campanha.

TikTok Ads

Não conectado

TikTok Ads Manager → Ferramentas → Business API, ou console.tiktok.com. Gere um token de acesso para o Advertiser ID da sua conta. Também entra no nível de campanha por enquanto.

Webhook de vendas

Cadastre a URL abaixo na sua plataforma de pagamento. Ela detecta sozinha se é Hotmart, Kiwify, Eduzz, PerfectPay, Stripe ou outra.

Para a venda aparecer ligada à campanha certa, o link do seu checkout precisa levar um utm_campaign (ou sck, no caso da Hotmart) com o nome da campanha do Facebook/Google/TikTok. Vendas sem isso caem em "Vendas não atribuídas" — nada se perde.

Conectar seus dados

Este painel roda inteiramente no seu navegador e, por segurança, não pode chamar endpoints externos diretamente a partir da página publicada. Para usar sua própria API: faça sua API retornar os dados nesse formato, busque o JSON (pelo seu backend, um script ou o console do navegador) e cole o resultado abaixo.
